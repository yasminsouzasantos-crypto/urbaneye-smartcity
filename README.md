# 🏙️ UrbanEye

> Plataforma inteligente para monitoramento e gestão de ocorrências urbanas.

## 📌 Sobre o projeto

O UrbanEye é uma aplicação desenvolvida com o objetivo de facilitar
o registro, acompanhamento e gerenciamento de problemas urbanos,
permitindo que cidadãos realizem chamados e que administradores
acompanhem e gerenciem as ocorrências.

## 🎯 Objetivo

Criar uma solução digital para aproximar cidadãos e órgãos
responsáveis pela manutenção urbana, tornando o processo de
registro e resolução de ocorrências mais rápido e transparente.

## ✨ Funcionalidades

### 👤 Cidadão
- Cadastro e login
- Registro de ocorrências
- Envio de fotos
- Localização automática via GPS
- Descrição do problema
- Acompanhamento do status do chamado
- Visualização dos próprios chamados
- Tempo estimado de resolução

### 🛠️ Administrador
- Dashboard de gerenciamento
- Visualização das ocorrências no mapa
- Filtros por categoria e gravidade
- Heatmap de ocorrências
- Ranking de regiões
- Acompanhamento dos chamados
- Visualização das fotos enviadas pelos cidadãos

## 🗺️ Mapa

O sistema utiliza mapas interativos para facilitar a localização
das ocorrências registradas.
